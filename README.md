# Secure-Student-Management-System
This is a desktop-based application that helps store and manage student data safely. The system allows only authorized users to access it through a secure login process. Passwords are stored in hashed format, which means they cannot be read directly from the database.
Student Management System — Manage Students. Simplify Records. Save Time.

🚀 A simple, secure, and user-friendly Student Management System built with Python, Tkinter & SQLite.

💡 Turning student record management into a simple, efficient, and organized digital experience.

# Secure-Student-Management-System
This is a desktop-based application that helps store and manage student data safely. The system allows only authorized users to access it through a secure login process. Passwords are stored in hashed format, which means they cannot be read directly from the database.
Student Management System — Manage Students. Simplify Records. Save Time.

🚀 A simple, secure, and user-friendly Student Management System built with Python, Tkinter & SQLite.

💡 Turning student record management into a simple, efficient, and organized digital experience.

🔐 Secure • ⚡ Fast • 🎨 User-Friendly • 🗄️ Database-Driven

Main Modules:

🔐 Login & Authentication
Provides secure admin/user login.
Protects student records from unauthorized access.

👨‍🎓 Student Registration
Add new student records.
Stores details such as name, age, course, etc.

📋 Student Records
Displays all registered students in a structured table.
Makes student information easy to view and manage.

✏️ Update Student
Allows existing student information to be modified.
Keeps records accurate and up to date.

🗑️ Delete Student
Removes unwanted or outdated student records from the database.

🔍 Search Student
Quickly finds students using available information.
Useful when managing a large number of records.

📊 Dashboard
Displays useful information such as total number of students.
Gives a quick overview of the system.

🔒 Data Security
Uses password hashing and basic data-protection techniques.
Helps protect sensitive information.
